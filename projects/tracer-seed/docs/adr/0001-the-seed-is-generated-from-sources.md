# 0001 — The seed is generated from sources

The seed must stay one Markdown file that a person can pass around, but at
180 KB it is too large to edit and review as one file. It is therefore
generated by `build.py` from fragments, real script files and `seed.json`,
and the generated file is committed so the handoff does not change. The
cost is that the next build overwrites a hand edit to the generated file;
`build.py --check` reports one before that happens.
