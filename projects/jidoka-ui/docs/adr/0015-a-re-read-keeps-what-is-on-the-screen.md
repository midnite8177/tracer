# A re-read keeps what is on the screen

A first read has nothing to keep, so the page blanks and says it is
reading. A re-read is different: the beads on the screen are one write old
and not wrong, and every write of the app causes one. The board reads a
whole backlog, which is three runs of `bd`, and the detail page reads the
bead, the backlog and the comments, so a page that blanked would empty
itself after each pick of a priority. Both pages therefore keep what they
are showing through a re-read, dim it and mark it. The detail page did
blank, and the fact strip is where a person triages, so it was the worse
of the two.
